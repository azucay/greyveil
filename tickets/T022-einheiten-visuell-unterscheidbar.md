# [T022] Einheiten visuell unterscheidbar machen

## Status
✅ Done

## Ziel
Schwertkämpfer und Bogenschützen sind optisch eindeutig unterscheidbar; Angriffe sind sichtbar und Gebäude werden von davor angegriffen.

## Kontext
Im MVP nutzt Greyveil geometrische Placeholder. Trotzdem müssen Einheitentyp und Kampfgeschehen für Beta-Tester sofort lesbar sein.

## Akzeptanzkriterien
- [x] Schwertkämpfer und Bogenschützen sind im Spiel eindeutig unterscheidbar.
- [x] Die Unterscheidung ist auch in typischer Zoom-/Spielansicht gut erkennbar.
- [x] Angriffe sind visuell erkennbar.
- [x] Bogenschützen-Angriffe zeigen einen fliegenden Pfeil oder vergleichbaren Projektil-Effekt.
- [x] Einheiten stehen beim Angriff auf Gebäude davor und nicht auf dem Gebäude.

## Definition of Done
- [x] Alle Akzeptanzkriterien erfüllt
- [x] Kein TypeScript-/Build-Fehler
- [x] Learning-Eintrag in AGENTS.md geschrieben
